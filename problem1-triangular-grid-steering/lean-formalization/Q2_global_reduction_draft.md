## 1. 记号与等距引理(情形 ii-a 的载体)

格点集 $\Lambda=\{m\mathbf e_1+n\mathbf e_2\}$, $\mathbf e_1=(20,0)$, $\mathbf e_2=(10,10\sqrt3)$;盘 = 以格点为心、半径 $9$ 的圆。第 $k$ 层 = $\{\max(|m|,|n|,|m+n|)=k\}$。

**引理 1(等距不变性)。** 设 $T$ 是 $\Lambda$ 的一个等距自同构(平移 $\mathbf e_1,\mathbf e_2$ 生成的平移群,或绕任一格点的 $60^\circ$ 旋转,或关于格线的反射)。则对任意折线路径 $p$ 与其像 $Tp$:
1. 每段直线段的航向、长度不变(平移/旋转/反射均保持);
2. 各段到各盘的最小净距不变;
3. 顶点转角与所需卡数不变。

*证:* 直接由等距保持内积与距离、以及 $T\Lambda=\Lambda$ 得。∎

**推论 2(第 k 层门缝构型是第 1 层的平移像)。** 第 $k$ 层门缝 $(k,0)$--$(k-1,1)$ 及第 $k+1$ 层门缝 $(k+1,0)$--$(k,1)$ 的四盘构型 $\{(k,0),(k-1,1),(k,1),(k+1,0)\}$ 是 $\{(1,0),(0,1),(1,1),(2,0)\}$ 在平移 $(20(k-1),0)$ 下的像。故任何只依赖这四盘局部几何的转角/净距/卡数下界,在第 $1\to2$ 层算出后,**对一切 $k$ 逐字成立**,无需重证。∎

(注:report 第 461 行"由平移不变性逐层成立"引用的是本推论;本推论此前未写成引理,现补。)

## 2. 出口窗口(回顾 report 的 lem:exit / cor:exitmax,不复证)

## 3. 层 $k\to k+1$ 过渡的情形分类(公理 C 的古典证明)

设路径已逃出第 $k$ 层(经某门缝,出射航向 $\varphi$),其后首次逃出第 $k+1$ 层(经某门缝,出射航向 $\varphi'$)。**核心断言:这一段净转角 $\ge 4\beta$,与出射位置、航向、选哪道门缝无关。** 分三情形。

### 3.1 情形 (i):对齐门链(同扇区相邻门)

即经 $(k,0)$--$(k-1,1)$ 出、经 $(k+1,0)$--$(k,1)$ 出,且途中从 $(k,0)$ 与 $(k,1)$ 之间通过。report 第 461–466 行已对任意 $s,\varphi$(含弦上转向)逐点证明净转角 $\ge 2\beta+2\beta=4\beta$。**不重证。**

### 3.2 情形 (ii):换门/跨扇区——关键新推导(约束和技巧)

不经过 $(k,0)$--$(k,1)$ 之间,即路径须绕经相邻的门缝族。按绕过方向分上、下,更远的门缝在 4.3 节按角点归纳。

**引理 3(上侧绕行,一般参数下界)。** 任何从 $(k,0)$--$(k-1,1)$ 门缝(出射航向 $\varphi\in[\beta,60^\circ-\beta]$)出发、经**上方**绕到 $(k,1)$--$(k-1,2)$ 门缝(出射航向 $\varphi'\in[\beta,60^\circ-\beta]$)且全程距 $(k-1,1)$、$(k,1)$ 两盘 $\ge9$ 的路径,净转角 $\ge 4\beta\approx16.63^\circ$(恰 $4$ 张卡);下界可被 $\varphi=\varphi'=60^\circ-\beta$ 的构造**取等**。

*证(约束和,前提必须写明):* 路径从两盘下方出发、最终到达其上方,故**存在时刻**其航向直线**从 $(k-1,1)$ 与 $(k,1)$ 两盘之间穿过**(两圆心分居该直线两侧;连续性:若路径始终不穿过两盘之间,则它从下到上必整体绕过两盘的同一侧——该"同侧"子情形归入 3.4 节的角点归纳,并同样给出 $\ge4\beta$)。设该时刻航向为 $\psi$,机器人位置为 $Q$,该航向直线到两盘心的距离为 $d_1,d_2$。两圆心分居直线两侧 ⟺ 两叉积 $(\mathbf w_1\times\hat u)$、$(\mathbf w_2\times\hat u)$ **同号**,此时三角不等式取**等号**:
$$d_1+d_2\ =\ \big|\,\mathbf w_1\times\hat u\,\big|+\big|\,\mathbf w_2\times\hat u\,\big|\ =\ \big|\,(\mathbf w_1-\mathbf w_2)\times\hat u\,\big|\ =\ 20\sin\psi ,$$
其中 $\mathbf w_i=Q-\text{盘心}_i$,$\mathbf w_1-\mathbf w_2=(-20,0)$(两盘心差向量)。碰撞约束 $d_1,d_2\ge9$ 给出 $20\sin\psi=d_1+d_2\ge18$,即
$$\psi\ \ge\ \arcsin(9/10)\ =\ 60^\circ+\beta\ \approx\ 64.158^\circ .$$
(注:上一版草稿在此处把不等式方向写反——"$d_1+d_2\ge20\sin\psi$"推不出任何结论;正确版本依赖"之间"前提下的**等式**。感谢四轮审计指出。)路径航向途中必须升到 $\ge60^\circ+\beta$;出发 $\varphi\le60^\circ-\beta$、终到 $\varphi'\le60^\circ-\beta$,故净转角
$$\Delta\ \ge\ \big[(60^\circ+\beta)-\varphi\big]+\big[(60^\circ+\beta)-\varphi'\big]\ \ge\ 4\beta .$$
∎

*取等构造(逐点净距已重算):* $\varphi=\varphi'=60^\circ-\beta=55.84^\circ$,出射点取 $(k,0)$--$(k-1,1)$ 门缝中点 $M_k=(20k-5,\ 5\sqrt3)$。
1. 沿 $55.84^\circ$ 飞至 $P_1=(20k-2.18,\ 5\sqrt3+4.16)$(该段到 $(k,0)$、$(k-1,1)$ 净距均恰 $9.0$;$\Delta x=2.82$, $2.82\tan55.84^\circ=4.16$);
2. 转 $2\beta=8.316^\circ$ 升至 $64.158^\circ$,沿 $(k-1,1)$--$(k,1)$ 的**内公切线** $\ell_1$($y=2.064(x-20k)+10\sqrt3$)飞行:该段到 $(k-1,1)$、$(k,1)$ 净距均 $9.0$,到 $(k-1,2)$ 最近 $12.99$(垂足 $x=20k-6.8$ 不在段上);
3. 在 $\ell_1$ 与第二条内公切线 $\ell_2$($(k,1)$--$(k-1,2)$ 的内公切线,方向 $55.84^\circ$,$y=1.474(x-20k)+18.61$)的**交点** $P_2=(20k+2.19,\ 21.84)$ 处转 $2\beta$ 降回 $55.84^\circ$($P_2$ 到 $(k,1)$ $9.02$、到 $(k-1,2)$ $12.99$、到 $(k-1,1)$ $13.0$);
4. 沿 $\ell_2$ 前进,该线在**门缝中点** $(20k+5,\ 25.98)$ 处穿过 $(k,1)$--$(k-1,2)$ 门缝弦,且整段到 $(k,1)$ 最近 $9.0$(垂足 $(20k+2.55,22.37)$ 在段上)、到 $(k-1,2)$ 最近 $10.0$。
总转角恰 $4\beta$。*(更正记录:第四轮审计提出的"过切点再走 $0.67$ m 后转向"与本构造的 $P_2$ **是同一点**——$0.67\cdot(\cos64.158^\circ,\sin64.158^\circ)=(0.29,0.60)$,$(20k+1.9,21.24)+(0.29,0.60)=(20k+2.19,21.84)=P_2$;v0.2 中"该修法距 (k−1,2) 仅 5.97 相撞"的记载是我方计算错误,予以撤回并致歉。)* ∎

**推论 4(下侧绕行)。** 绕 $(k,0)$ **下方**、经 $(k+1,0)$--$(k+1,-1)$ 门缝出:同法(取 $(k,0)$、$(k,-1)$ 两盘作约束和)得途中航向必须 $\le-(60^\circ+\beta)$;出发 $\varphi\ge\beta$,故俯冲 $\ge60^\circ+2\beta\approx68.3^\circ$,回升到出口窗口(下侧窗口为 $[-(60^\circ-\beta),-\beta]$)再 $\ge60^\circ$。净转角 $\ge128.3^\circ\ge4\beta$。∎

### 3.3 情形 (iii):折返路径

以**首次逃出第 $j$ 层**的时刻 $t_j$($j=2,3,\dots,n$)切分:$t_2<t_3<\dots<t_n$(栅栏嵌套,时刻严格递增)。区间约定:**半开区间 $[t_j,\ t_{j+1})$ 上的卡归入第 $j$ 段**(即恰在 $t_j$ 时刻生效的转向卡归入 $j\to j+1$ 段;恰在 $t_{j+1}$ 的卡归入下一段)。于是各段互不相交、卡数相加 $\le$ 总卡数;折返到内侧再出来的路径,其"再来一次"的部分落在后续某段内,不破坏分段。每段都是一次完整的层过渡,按情形 (i)/(ii) 净转角 $\ge4\beta\ge4$ 卡。故
$$C\ \ge\ N(2)\ +\ \sum_{j=2}^{n-1} 4\ =\ 9+4(n-2)\ =\ 4n+1 .$$
(注:该半开区间约定与 Lean 方案 Counting.lean 的记账引理**逐字对齐**,古典与机器两版互证。)

### 3.4 同侧绕行与更远门缝(单对界,修正版)

引理 3 覆盖"从 $(k-1,1)$、$(k,1)$ **之间**穿过"的子情形($\theta_{12}=0^\circ$ 对)。一般情形用**单对界**统一处理,不需要逐对累加的归纳(五轮审计指出:各对盘的 $\psi$ 约束取 **max** 不求和,累加归纳是方向性错误;正确做法是对路径"从之间穿过"的**第一对**盘给出一个下界,单对即可)。

**单对界。** 设路径在层过渡中从某对相邻盘 $\{c_1,c_2\}$(盘心差向量方向角 $\theta_{12}\in\{0^\circ,60^\circ,120^\circ\}$)之间穿过(连续性保证:任何从栅栏内侧到外侧的路径必存在这样的第一对;栅栏由相邻盘对的间隙构成)。与引理 3 完全相同的约束和给出:存在时刻航向
$$\psi\ \ge\ \theta_{12}+\arcsin(9/10)\ =\ \theta_{12}+60^\circ+\beta .$$
出发门缝与出口门缝的出射航向**均** $\le60^\circ-\beta$——每道门缝的绝对航向窗口都是 $[\beta,60^\circ-\beta]$(只依赖门缝自身的两盘;六重对称下各方向门缝同此窗口,注:五轮审计指正,v0.2 的"窗口随 θ₁₂ 平移"是错的)。故净转角
$$\Delta\ \ge\ \big[(\theta_{12}+60^\circ+\beta)-\varphi\big]+\big[(\theta_{12}+60^\circ+\beta)-\varphi'\big]\ \ge\ 2\big[\theta_{12}+2\beta\big]\ =\ 2\theta_{12}+4\beta .$$
三个方向逐项:$\theta_{12}=0^\circ$: $4\beta$;$\theta_{12}=60^\circ$: $120^\circ+4\beta\approx136.6^\circ$;$\theta_{12}=120^\circ$: $240^\circ+4\beta\approx256.6^\circ$。全部 $\ge4\beta$(即 $\ge4$ 张卡;60°/120° 情形对应 28/52 卡,远超 4)。∎

(注:v0.2 的两处错误按五轮审计修正:① 盘对标注——$(k-1,2)$--$(k,2)$ 对是 $\theta_{12}=0^\circ$,$(k,1)$--$(k-1,2)$ 对才是 $\theta_{12}=120^\circ$;② 出口窗口——每道门缝的绝对窗口只依赖自身弦方向,不依赖"盘对"的 $\theta_{12}$;v0.2 的"$[60^\circ+\beta,120^\circ-\beta]$"与据此算的 76.6° 作废,替换为上式。)

## 4. 结论(草稿状态)

1. **公理 C 升级为定理**:任意合法逃出路径,按首次逃出时刻切分后,每一层段要么是对齐门链(report 已有 4β 下界)、要么是绕行(引理 3/推论 4/3.4 节,均 $\ge4\beta$)。全局归约**已证**,不再需要作为假设。
2. 第二问下界 $N(n)\ge4n+1$ 的古典证明由此完整:定理 1(9 卡)+ 逐层 4β + 本归约 + 3.3 节切分。
3. Lean 保底级方案的公理表相应缩减:**公理 A(第一问)+ 公理 B(门到门 4β)** 两条;公理 C 由本定理取代(其 Lean 化属于"进阶级",不阻塞保底级)。
