## 2. P1 — 区间认证原语 + 基准点三方对齐(✅ 完成,已复核)

**子代理 I / saI**　**报告**:`report_q3_certp1_saI.md`　**代码**:`q3_certp1_seg.py`、`q3_certp1_ray.py`、`q3_certp1_align.py`

### 2.1 方法
- 原语一 `cert_seg_min(p0,v,u,t0,t1,q0)`:单盘 Lipschitz |d'/dt| ≤ v+ω·|q0|,左优先递归二分,unsafe 定位到空间直径 <1e-4 m;精确切点退化判 `indet`(保守不误判)。
- 原语二 `cert_ray(p0,u,v,t0,r_cap=460)`:按**弧长** L 参数化(修正过把弧长步当半径步的 bug),返回认证区间 `[r_safe, r_coll]`(r_safe 为下界、粒度 ~0.09 m;r_coll 为上界、粒度 0.1 mm)。
